# Perplexity Chat Bulk Exporter

Perplexity の対話ログをブラウザ拡張（Manifest V3）でエクスポートするサンプルです。

## まずこれだけ（3分版）
「どう使うの？」に最短で答えると、次の4ステップです。

1. `extension/` を Chrome/Edge の「パッケージ化されていない拡張機能」として読み込む
2. Perplexity をログインした状態で開く
3. 1件だけなら「現在の対話を JSON ダウンロード」を押す
4. まとめてなら履歴リンクが見えるページで「複数スレッドを ZIP ダウンロード」を押す

これで、ローカルPCにエクスポートファイルが保存されます（外部送信なし）。

## できること
- 現在開いている対話を JSON で保存
- 履歴ページ等で見つけた複数スレッドを巡回して抽出
- JSON + Markdown を ZIP にまとめて一括ダウンロード

## ディレクトリ構成
- `extension/manifest.json`: 拡張機能設定
- `extension/src/popup.html`, `extension/src/popup.js`: UI と実行ボタン
- `extension/src/content.js`: Perplexity ページから対話を抽出
- `extension/src/background.js`: 一括収集・ZIP生成・ダウンロード

## セットアップ
1. このリポジトリをローカルに配置
2. Chrome/Edge で `chrome://extensions`（Edge は `edge://extensions`）を開く
3. 開発者モードを ON
4. 「パッケージ化されていない拡張機能を読み込む」から `extension/` を選択

## あなた向けの操作ガイド（画面で何を押すか）

### 0) 事前確認
- Perplexity にログイン済みであること
- 履歴/スレッド一覧が見えるページに移動できること（複数DL時）

### 1) 単一対話だけ保存したいとき
1. 保存したいスレッドを開く
2. 拡張アイコンを押す
3. **「現在の対話を JSON ダウンロード」** を押す
4. 保存ダイアログで保存先を選ぶ

出力ファイル: `perplexity-export/<タイトル>.json`

### 2) 複数スレッドをまとめて保存したいとき
1. Perplexity の履歴一覧・サイドバーなど、スレッドリンクが並ぶ画面を開く
2. 拡張アイコンを押す
3. **「複数スレッドを ZIP ダウンロード」** を押す
4. ステータスに `抽出中... n/総数` が出るので完了まで待つ
5. ZIP を保存する

ZIP の中身:
- 各スレッドの `*.json`
- 各スレッドの `*.md`
- 成功/失敗件数が入った `summary.json`

### 3) うまくいかない時（まずここを見る）
- `Perplexityページを開いたタブで実行してください。`
  - Perplexity 以外のタブで実行しています。対象タブに戻って再実行
- `スレッドURLを見つけられませんでした。`
  - 一覧リンクが画面に出ていないページです。履歴一覧ページへ移動
- `すべてのスレッド抽出に失敗しました。`
  - ログイン状態切れか、Perplexity のUI変更の可能性あり。再ログイン後に再試行

## 実運用のコツ
- 最初は2〜3件だけで試してから大量エクスポートする
- タイトルが長い/記号が多い場合、ファイル名は安全な文字に置換される
- Perplexity のUI変更で抽出精度が落ちる場合は `content.js` のセレクタ更新が必要

## 使い方
### 単一対話のエクスポート
1. Perplexity の対象スレッドページを開く
2. 拡張ポップアップで「現在の対話を JSON ダウンロード」を押す

### 複数スレッドの一括エクスポート
1. Perplexity の履歴一覧やサイドバーにスレッドリンクが見えるページを開く
2. 拡張ポップアップで「複数スレッドを ZIP ダウンロード」を押す
3. 進捗表示のあと、ZIP が保存される

## 権限と理由
- `activeTab`: 現在表示中の Perplexity タブにアクセス
- `tabs`: 一括エクスポート時にスレッドURLを順次開く
- `scripting`: 将来の動的注入拡張用（現状は content script 常駐）
- `downloads`: JSON / ZIP の保存
- `storage`: ユーザー設定保存用（拡張余地）
- `host_permissions` (`https://*.perplexity.ai/*`): 対象サイトへのアクセス

## プライバシー
この実装は抽出データを外部送信しません。生成したファイルをローカルにダウンロードするだけです。

## 既知の制限
- Perplexity の DOM 構造が変わると抽出セレクタが壊れる場合があります
- 一括処理はページ件数に応じて時間がかかります
- ログイン状態でないと取得できないスレッドがあります
- 履歴リンクがDOMに表示されていないページでは複数スレッドを収集できません

## 動作確認のすすめ
1. まず 1〜2 スレッドで単体・一括を試す
2. 問題なければスレッド数を増やす
3. 失敗時はポップアップのエラーメッセージと `summary.json` を確認する
